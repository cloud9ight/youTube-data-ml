# youTube-data-ml

**Please go through Global YouTube Statistics.csv first**

- Executed an end-to-end data analysis project in R (caret, rpart) involving extensive data cleaning, feature engineering, comparison of feature selection methods, and building classification models (Logistic Regression, Decision Trees) to predict YouTuber income category.
- Evaluated models via cross-validation and ROC/AUC (achieving ~0.86 AUC with Decision Tree), identified key earnings predictors (subscriber growth, views, uploads), explored clustering (PCA, K-means), and developed an R Shiny app for interactive visualization.
